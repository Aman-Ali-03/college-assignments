# C Programming Practice

This repository contains my C programming practice programs and problem-solving exercises as I learn and improve my programming skills.

The goal of this repository is to strengthen my understanding of C programming fundamentals, develop logical thinking, and improve my problem-solving abilities through hands-on coding.

## 📚 Topics Covered

- **Basic Programming:** Input/output, variables, data types, and operators
- **Conditional Statements:** `if-else`, nested conditions, and `switch`
- **Loops:** `for`, `while`, and `do-while`
- **Functions:** User-defined functions, function arguments, and return values
- **Arrays:** One-dimensional, two-dimensional, and multidimensional arrays
- **Strings:** String handling and standard string functions
- **Pointers:** Pointer basics and call by value vs. call by reference
- **Structures:** Working with structures and storing related data
- **Recursion:** Introduction to recursive problem-solving
- **File Handling:** Basic file operations

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder in your code editor.

3. Compile a C program using GCC:

   ```bash
   gcc filename.c -o output
   ```

4. Run the compiled program:

   ```bash
   ./output
   ```

   On Windows:

   ```bash
   output.exe
   ```
